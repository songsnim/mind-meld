Агенты выдают код быстрее, чем человек его читает. Узкое место ревью — не нажатие «approve», а понимание того, что именно вы одобряете. Название взято из [вулканского слияния разумов](https://en.wikipedia.org/wiki/Vulcan_(Star_Trek)#Mind_meld) — это путь в голову агента.

## Два способа применения

**Путь 1 — есть PR на ревью.** Вызовите оркестратор, и он проведёт весь процесс.

```
/mind-meld #42
```

**Путь 2 — всё остальное, что вам непонятно.** Вызовите инструмент напрямую и укажите что угодно:
понятие, модуль, алгоритм, статью, только что прочитанную фразу.

```
/microworld "consistent hashing"
/socratic src/scheduler.ts
/five-whys "почему в этом repo закреплены все версии"
/first-principles "vector clocks"
```

Путь 1 — измеряемый процесс с проходным баллом. Путь 2 — один инструмент, по требованию и на столько,
сколько нужно. Инструменты за вас выбирает только оркестратор; на пути 2 выбираете вы.

## Путь 1: ревью PR

```
/mind-meld #42
```

1. **microworld** — интерактивный HTML-мир, воплощающий сам механизм, а не пересказ изменения. Вы его
   исследуете, сессия ждёт.
2. **quiz** — несколько вопросов с однозначным ответом, чтобы найти пропуск. Он не выставляет зачёт.
3. **Один глубокий инструмент** — `feynman`, `five-whys`, `socratic` или `first-principles`, в
   зависимости от провалившейся оси.
4. **short-essay** — объясните это коллеге по памяти. Оценка по трём осям: **что** изменилось,
   **почему** именно так, **что может сломаться**.
5. **Проход — 8/10 по каждой оси**, иначе доработка. Две неудачные доработки меняют глубокий
   инструмент; четыре неудачи завершают сессию и прямо об этом сообщают — это свидетельство того, что
   изменение неясно, а не того, что вы медленно думаете.

Результат — `.mind-meld/<цель>-report.md`: оценки, что осталось непонятным, и вопросы, которые нужно
вернуть агенту. Ничего не публикуется автоматически. Одобряете вы, а не mind-meld.

Ветка, диапазон коммитов, путь или вовсе без аргумента (рабочий diff) работают так же, как номер PR.

## Путь 2: любой инструмент, на чём угодно

Ни оценок, ни обязательного порядка. Выбирайте по тому, на чём застряли:

| Застряли на | Вызов |
| --- | --- |
| Не могу представить, как это работает | `/microworld <объект>` |
| Хочу узнать, что упустил | `/quiz <объект>` |
| Не могу сказать, что сломается | `/socratic <объект>` |
| Кажется, понял, но просто объяснить не могу | `/feynman <объект>` |
| Не вижу, почему сделано именно так | `/five-whys <объект>` |
| Незнакома сама терминология | `/first-principles <объект>` |
| Хочу оценку своего понимания | `/short-essay <объект>` |

Аргумент — произвольный текст. И `/microworld "CRDT merge"`, и `/microworld src/merge.ts` допустимы.

## Установка

Скопируйте только блок своего агента.

**Claude Code**

```
/plugin marketplace add songsnim/mind-meld
/plugin install mind-meld@mind-meld
```

**Codex CLI**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.codex/skills
ln -sfn ~/.mind-meld/skills/* ~/.codex/skills/
```

**opencode**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.config/opencode/skills
ln -sfn ~/.mind-meld/skills/* ~/.config/opencode/skills/
```

Обновление — `git -C ~/.mind-meld pull`, симлинки подхватят. Claude Code обновляется через
marketplace.

## Что внутри

Восемь скиллов: `mind-meld` и семь инструментов, между которыми он маршрутизирует — `microworld`,
`quiz`, `socratic`, `feynman`, `five-whys`, `first-principles`, `short-essay`. Сам собой срабатывает
только `mind-meld`; остальные семь — только по явному вызову, поэтому просьба объяснить никогда не
превращается неожиданно в сократический диалог.

## Примечания

- Без состояния. Оценки между сессиями не запоминаются.
- Вывод идёт в `.mind-meld/`, добавленный в `.git/info/exclude` — проверяемый diff остаётся чистым.
- Сессия говорит на вашем языке. Оценка эссе на неродном языке измеряет письмо, а не понимание.
- Ни скриптов, ни зависимостей, ни сборки. Восемь файлов `SKILL.md`.
