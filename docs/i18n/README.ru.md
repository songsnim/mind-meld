# mind-meld

Набор инструментов, чтобы понять незнакомые понятия, знания и проектные решения, которые агент
притащил, пока писал код, — прежде чем им доверять. Чаще всего это происходит при разборе pull
request, только что открытого агентом, но целью может быть любой модуль, алгоритм, библиотека,
архитектурное решение или само понятие.

Агенты выдают код быстрее, чем человек его читает. Узкое место ревью — не нажатие «approve», а
понимание того, что именно вы одобряете. Название взято из [вулканского слияния
разумов](https://en.wikipedia.org/wiki/Vulcan_(Star_Trek)#Mind_meld) — это путь в голову агента.

## Как идёт сессия

```
/mind-meld 42
```

1. **microworld** — интерактивный HTML-мир, воплощающий сам механизм, а не пересказ изменения. Вы его
   исследуете, сессия ждёт.
2. **quiz** — несколько вопросов с однозначным ответом, чтобы найти пропуск. Он не выставляет
   зачёт.
3. **Один глубокий инструмент** — `feynman`, `five-whys`, `socratic` или `first-principles`, в
   зависимости от провалившейся оси.
4. **short-essay** — объясните это коллеге по памяти. Оценка по трём осям: **что** изменилось,
   **почему** именно так, **что может сломаться**.
5. **Проход — 8/10 по каждой оси**, иначе доработка. Две неудачные доработки меняют глубокий
   инструмент; четыре неудачи завершают сессию и прямо об этом сообщают — это свидетельство того, что
   изменение неясно, а не того, что вы медленно думаете.

Результат — `.mind-meld/<цель>-report.md`: оценки, что осталось непонятным, и вопросы, которые нужно
вернуть агенту. Ничего не публикуется автоматически. Одобряете вы, а не mind-meld.

Каждый инструмент вызывается и отдельно.

```
/microworld src/scheduler.ts
/five-whys 42
/first-principles "vector clocks"
```

## Установка

Скопируйте только блок своего агента.

**Claude Code**

```
/plugin marketplace add songsnim/mind-meld
/plugin install mind-meld@mind-meld
```

**Codex CLI**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.codex/skills
ln -sfn ~/.mind-meld/skills/* ~/.codex/skills/
```

**opencode**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.config/opencode/skills
ln -sfn ~/.mind-meld/skills/* ~/.config/opencode/skills/
```

**Cursor**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.cursor/skills
ln -sfn ~/.mind-meld/skills/* ~/.cursor/skills/
```

**Hermes**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.hermes/skills
ln -sfn ~/.mind-meld/skills/* ~/.hermes/skills/
```

Обновление — `git -C ~/.mind-meld pull`, симлинки подхватят. Claude Code обновляется через
marketplace.

## Что внутри

| Скилл | Что делает |
| --- | --- |
| `mind-meld` | Оркестратор. Маршрутизирует остальные. |
| `microworld` | Интерактивный HTML-мир, воплощающий механизм. |
| `quiz` | Несколько однозначных вопросов; находит пробел. |
| `socratic` | По одному вопросу, пока вы сами не увидите, что ломается. |
| `feynman` | Объясните простыми словами; расплывчатые места отмечаются. |
| `five-whys` | Спуск до ограничения, которое вынудило решение. |
| `first-principles` | Сборка незнакомой идеи заново из примитивов. |
| `short-essay` | Измерительный прибор. Оценка и доработка, пока не выдержит. |

Сам собой срабатывает только `mind-meld`. Остальные семь — только по явному вызову, поэтому просьба
объяснить никогда не превращается неожиданно в сократический диалог.

## Примечания

- Без состояния. Оценки между сессиями не запоминаются.
- Вывод идёт в `.mind-meld/`, добавленный в `.git/info/exclude` — проверяемый diff остаётся чистым.
- Сессия говорит на вашем языке. Оценка эссе на неродном языке измеряет письмо, а не понимание.
- Ни скриптов, ни зависимостей, ни сборки. Восемь файлов `SKILL.md`.
