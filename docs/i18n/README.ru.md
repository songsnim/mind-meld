Чтение объяснения создаёт впечатление понимания, а не понимание. mind-meld закрывает этот разрыв, измеряя его: строит мир, который можно исследовать, задаёт вопросы, прорабатывает слабое место и оценивает ваше собственное объяснение, пока оно не выдержит. Название — от [вулканского слияния разумов](https://en.wikipedia.org/wiki/Vulcan_(Star_Trek)#Mind_meld): путь в другой разум — эксперта, автора, агента.

## Два способа применения

**Путь 1 — полная сессия.** Вызовите оркестратор с тем, что хотите понять; он проведёт весь процесс.

```
/mind-meld "consistent hashing"
/mind-meld src/scheduler.ts
/mind-meld #42
```

**Путь 2 — один инструмент, по запросу.** Вызовите инструмент напрямую с чем угодно: концепция,
модуль, алгоритм, статья, только что прочитанная фраза.

```
/microworld "consistent hashing"
/socratic src/scheduler.ts
/five-whys "почему в этом repo закреплены все версии"
/first-principles "vector clocks"
```

Путь 1 — измеряемый конвейер с проходным баллом. Путь 2 — один инструмент, сколько захотите.
Инструменты за вас выбирает только оркестратор; на пути 2 выбираете вы.

## Путь 1: полная сессия

```
/mind-meld "consistent hashing"
```

1. **Microworld** — интерактивный HTML-мир, воплощающий сам механизм, а не его пересказ. Вы его
   исследуете. Сессия ждёт.
2. **Quiz** — несколько вопросов с однозначным ответом, чтобы найти, что вы упустили. Зачёт он не ставит.
3. **Один глубокий инструмент** — `feynman`, `five-whys`, `socratic` или `first-principles`, в
   зависимости от того, что упущено.
4. **Короткое эссе** — объясните коллеге по памяти. Концепция получает одну оценку; изменение кода
   оценивается по трём осям: **Что** изменилось, **Почему** так, **Что может сломаться**.
5. **Зачёт — 8/10 по каждой оси**, иначе доработка. Две неудачные доработки меняют глубокий инструмент;
   четыре неудачи завершают сессию с прямым сообщением об этом — это признак того, что неясен сам
   предмет, а не вы.

Для изменения кода создаётся `.mind-meld/<цель>-report.md`: оценки, что осталось неясным, и вопросы,
которые стоит вернуть тому, кто это сделал. Для концепции отчёт необязателен. Ничего не отправляется за
вас, а что решать на основе этого понимания — решать вам.

Целью может быть концепция, путь, номер PR, ветка или диапазон коммитов. Без аргумента берётся тема
текущего разговора.

## Путь 2: любой инструмент, на чём угодно

Ни оценок, ни обязательного порядка. Выбирайте по тому, на чём застряли:

| Застряли на | Вызов |
| --- | --- |
| Не могу представить, как это работает | `/microworld <объект>` |
| Хочу узнать, что упустил | `/quiz <объект>` |
| Не могу сказать, что сломается | `/socratic <объект>` |
| Кажется, понял, но просто объяснить не могу | `/feynman <объект>` |
| Не вижу, почему сделано именно так | `/five-whys <объект>` |
| Незнакома сама терминология | `/first-principles <объект>` |
| Хочу оценку своего понимания | `/short-essay <объект>` |

Аргумент — произвольный текст. И `/microworld "CRDT merge"`, и `/microworld src/merge.ts` допустимы.

## Установка

Скопируйте только блок своего агента.

**Claude Code**

```
/plugin marketplace add songsnim/mind-meld
/plugin install mind-meld@mind-meld
```

**Codex CLI**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.codex/skills
ln -sfn ~/.mind-meld/skills/* ~/.codex/skills/
```

**opencode**

```sh
git clone https://github.com/songsnim/mind-meld ~/.mind-meld
mkdir -p ~/.config/opencode/skills
ln -sfn ~/.mind-meld/skills/* ~/.config/opencode/skills/
```

Обновление — `git -C ~/.mind-meld pull`, симлинки подхватят. Claude Code обновляется через
marketplace.

## Что внутри

Восемь скиллов: `mind-meld` и семь инструментов, между которыми он маршрутизирует — `microworld`,
`quiz`, `socratic`, `feynman`, `five-whys`, `first-principles`, `short-essay`. Сам собой срабатывает
только `mind-meld`; остальные семь — только по явному вызову, поэтому просьба объяснить никогда не
превращается неожиданно в сократический диалог.

## Примечания

- Без состояния. Оценки между сессиями не запоминаются.
- Вывод идёт в `.mind-meld/`, добавленный в `.git/info/exclude` — рабочее дерево остаётся чистым.
- Сессия говорит на вашем языке. Оценка эссе на неродном языке измеряет письмо, а не понимание.
- Ни скриптов, ни зависимостей, ни сборки. Восемь файлов `SKILL.md`.
